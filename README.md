# FastAPI Document Search Service

Сервис для поиска документов по тексту с использованием FastAPI, PostgreSQL и Elasticsearch.

## Технологический стек
- Python 3.10+, FastAPI (async)
- PostgreSQL (SQLAlchemy 2.0, asyncpg)
- Elasticsearch 7.x
- Docker & Docker Compose
